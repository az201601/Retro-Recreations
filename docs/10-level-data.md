# 10 — 关卡数据解码（阶段 C，M2）

> 动态验证（FCEUX）已确认：状态 3 = 过场（CHR 24/25 Chip 大头像 → 31/14 字体），状态 4 = 第一关开始（CHR 15/0，银行 15 主图形）。
> 本文档记录银行 2（关卡）、银行 5（音乐）、`$DAC7` 表的静态解码结果。

## 1. `$DAC7` 表（16 区域 CHR + 关卡指针）

`$DAC7`（固定银行 7，`$DAC7–$DAD6`）16 个指针，指向银行 2（`$BD84–$BEE2`），由 `$D7AD` 按区域索引 `$71` 选择，`$D903` 加载。

### 1.1 条目格式（`$D903` 反汇编）

```
Y=0: CHR0 -> $1D/$1F
Y=1: CHR1 -> $1E/$20
Y=2: ptr_lo -> $AE, ptr_hi -> $AF, $13, $14
Y=3: ptr2_lo -> $B2, ptr2_hi -> $B3, $19, $1A
Y=4: -> $0314 (CMP #$18 -> $0315)
Y=5: -> $02FC/$02FD
Y=6: -> $74
Y=7: -> $7B, Y=8: $7C, Y=9: $7D, Y=10: $7E, ...
```

## 2. 银行 2（关卡数据，16KB）

- 偏移：PRG `0x4000–0x7FFF`（文件 `0x4010–0x8010`）
- 头部（`$0000`）：`01 0E 04 01 02 03 01 0E 04 01 02 03 01 0E 04 01 01 07 08 01 05 06 ...`
- 模式：`01 XX YY 01 AA BB` 重复，疑似 `[类型, 图块, 属性]` 三元组或 `[X, Y, 图块]` 坐标
- `$0706`（idx0 ptr）：`2D 2D 01 09 00 29 00 00 29 05 21 09 A2 A1 A1 A0 ...`（另一格式，疑似图块地图）
- 尾部：`FF` 填充 + `78 EE E1 FF D8 4C 00 C0`（与其他 PRG 银行相同尾）

### 2.1 待解

- 三元组字段含义（`01` = 类型？`0E` = 图块 14？`04` = 属性？）
- 图块地图尺寸（32×30？更大？）
- 与 nametable（`$2000`）的写入对应（`$C309` 上传，A=页，X=lo，Y=hi）

## 3. 银行 5（音乐指针表，16KB）

- 偏移：PRG `0xA000–0xDFFF`（文件 `0xA010–0xE010`）
- 头部 16 指针（LE）：`$8014, $809C, $80E2, $8128, $813A, $815A, $8148, $81EA, $82FA, $82E2, $845A, $8411, $8AAF, $8AB5, $8ABD, $8AC7`
- 用途：`$8200` 音乐调度（A=轨号）经 `$8220` 跳表读取，`$812D/$8154` 脉冲输出
- FCEUX 验证：状态 3 中 PRG 2↔5 每 ~5 帧交替 = 关卡数据（银行 2）+ 音乐（银行 5）流式读取
