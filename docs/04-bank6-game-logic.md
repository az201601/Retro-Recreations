# 04 — 游戏逻辑银行（`$8000–$BFFF`，PRG 银行 6）

> NMI 经 `JSR $8000` 进入本银行。反汇编：`disassembly/bank6_8000.asm`（9709 行）。
> 递归追踪仅覆盖入口分发（481 字节），其余为数据驱动（间接跳转 + 脚本流），需结合脚本解码（阶段 C）。

## 1. 入口（`$8000`）— 每帧主循环

```asm
$8000 LDA $F0 / BMI $8007 / JSR $8200   ; 若 $F0>=0：音乐/音效调度（$8200）
$8007 LDY #$06 / LDX $FC / BEQ $8011    ; Y=6（实体数？），X=$FC（玩家索引？）
      LDY #$02 / LDX #$04               ; 否则 Y=2，X=4
$8011 STX $F7
$8013 TYA / PHA                         ; 循环 Y 次（实体槽位）
      LDX $F7 / LDA $F1 / AND $861C,X / BEQ $8027  ; 掩码表 $861C = 01 02 04 08 10 20 40 80
        JSR $839E                       ;   实体更新 A
        JSR $8670                       ;   实体脚本解释器（X=3 玩家？）
        JSR $803F                       ;   实体移动/物理
$8027 INC $F7 / PLA / TAY / DEY / BNE $8013
      JSR $81C2                         ; 音乐序列器 tick
      JSR $80A9                         ; 音效分发
      LDA $F1 / ORA $F2 / STA $F1 / LDA #$00 STA $F2  ; 标志合并
      RTS
```

## 2. 实体系统

**实体数组**：`$0700–$07FF`，X 为槽位索引。字段（`$803F` 证据，🔍 待动态验证）：

| 偏移（相对 X） | 含义（推测） |
|---|---|
| `$079C,X` | X 位置 / 状态（bit7=禁用） |
| `$07A2,X` | 动画计数 / 帧 |
| `$07A8,X` | 脚本指针偏移 |
| `$07AE,X` | X 速度累加 |
| `$07B4,X` | Y 速度累加 |
| `$07BA,X` | X 速度 |
| `$07C0,X` | Y 速度 |
| `$0790,X` | 调色板/属性（`$86BE` 写 `$C0` 掩码） |
| `$07C6,X` | 音符/音效 ID（`$86D0`） |
| `$07CC,X` | 音符长度 |
| `$07D2,X` | 声音使能 |
| `$07D8,X` | Sweep |
| `$07DE,X` | Sweep 计数 |
| `$07EA–$07EB` | 脚本指针（`$865D`） |
| `$07F0,X` | 实体类型（`$85ED` 交换） |

**脚本流**（`$803F` + `$8670`）：`$F5/$F6` 指针，`($F5),Y` 逐字节读，`$FE`=终止。
`$92B6,Y` 为脚本指针表（`$92E0/$9323/$935A/…`，见 `docs/05`）。
`$8670` 操作码（X=3 时执行）：

| 字节 | 动作 |
|---|---|
| `$FF` | 终止（清 `$07EE/$07EF`） |
| `$E0–$FF`（`AND #$E0 == $E0`） | 设 `$0790,X`（调色板，`ROR×3 AND #$C0`） |
| `$40` | 设 `$07ED`（音高？）+ 读下一字节→`$07EC`，`INC $07D3` |
| `$80/$A0` | 设 `$079C,X`（`AND #$3F`），清 `$07A8/$07A2` |
| `$00–$1F` | 设 `$07C6,X`（`AND #$1F`），清 `$07CC`，`INC $07D2` |

**实体模板**（`$82E3`）：`LDA $8328,X STA $0700,X / LDA #$80 STA $0766,X / LDA #$92 STA $076C,X…`
`$8328` 表：`00 10 20 30 40 50 0A AA BD B5 87 85 F5 BD B6 87 85 F6…`（待解码）。

**移动**（`$803F`）：`LDY $079C,X / BMI 禁用 / LDA $07A2,X BNE 动画 / TYA ASL TAY LDA $92B6,Y STA $F5/$F6 / LDY $07A8,X / LDA ($F5),Y CMP #$FE BEQ 终止…`
`$8092`：`$07AE += $07BA`，`$07B4 += $07C0`，`DEC $07A2`（重力/惯性）。

## 3. 音乐系统

**调度**（`$8200`）：

```
ORA #$80 / STA $F0 / AND #$7F / BEQ $8274（停）
CMP #$79 / BCS $820F / JMP $832E
$820F SBC #$79 / ASL / TAY / LDA $8220,Y STA $F3 / LDA $8221,Y STA $F4 / JMP ($00F3)
```

**跳表**（`$8220`，7 项）：`$822E / $8233 / $8252 / $8249 / $825B / $8268 / $8274`

| 入口 | 动作 |
|---|---|
| `$822E` | `LDA #$00 STA $FC / RTS`（停） |
| `$8233` | `LDA #$01 STA $FC` + 清 APU（`$4000/$4004/$400A/$400B/$400C=0`） |
| `$8249` | `$F9=0 / $F8=1` |
| `$8252` | `$F8=0 / $F9=1` |
| `$825B` | `$F8=$F9=0` + 初始化通道（`JSR $82E3` ×4） |
| `$8268` | 通道初始化（X=0,Y=4 / X=4,Y=2） |
| `$8274` | APU 初始化：清 `$4000–$4013`，`$4000=$08/$4004=$08/$4008=$40/$400C=$10/$4015=$8F/$4017=$C0`，清 `$0700–$07FD`，`$07EA=$B5/$07EB=$92`，`JSR $82E3` ×4 |

**序列器**（`$81C2/$81E5`）：`$F8` 使能，`$FA` 计数（0–3），`$FB` 计数（0–15），`$F9` 方向。
**脉冲输出**（`$812D/$8154`，Y=通道×4）：

```
$812D: LDA $07B4,X LSR×4 / SEC SBC $0796,X / … / ORA $0790,X / ORA #$30 / STA $4000,Y  ; 音量/占空比
$8154: LDA $07D2,X / ORA $07DE,X / BEQ 跳过 / LDA $07D8,X STA $4001,Y（sweep）/ LDA $07C6,X/$07CC,X → $F3/$F4 LSR/ROR → STA $4002,Y（周期低）/ STA $4003,Y（周期高 + $F8）
$8193: 脉冲2（$4004/$4006/$4007，$07B7/$0799/$07ED/$07EC）
$839A: STA $400C（噪声）
```

> 音乐数据本身在银行 5 指针表 + 银行 6 `$07xx` 实体字段中，完整解码待阶段 C。GMS 侧先用占位音频（`scr_nes_apu`）。

## 4. 音效分发（`$80A9` + `$80D0` + `$80E5`）

```
$80A9: LDA $FC / BNE $80BE
       LDX #$00 / LDA $F1 / AND $80D0,X / BNE 跳过 / JSR $80D4（×4）
$80BE: LDX #$04 / LDA $F1 / AND $861C,X / BEQ 跳过 / JSR $80D4（×2，X=4,5）
$80D4: JSR $0A8A???（实为数据误读，$80D0 为掩码表）
       TAY / LDA $80E5,Y STA $F3 / LDA $80E6,Y STA $F4 / JMP ($00F3)
```

**跳表**（`$80E5`）：`$80F1 / $80FC / $8112 / $811D / $8107 / $8122`（6 项，均为 `JSR $812D / JSR $8154 / JMP $80E4` 变体，Y=0/4/8/$0C）。
