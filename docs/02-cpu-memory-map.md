# 02 — CPU 内存映射与 RAM 变量表

> NES CPU 地址空间：`$0000–$1FFF` RAM（镜像至 `$07FF`）、`$2000–$3FFF` PPU、`$4000–$4017` APU/手柄、`$8000–$FFFF` PRG ROM。
> 本文档汇总固定银行 + 游戏逻辑银行中已确认的 RAM 变量。标注：✅ 已确认 / 🔍 推测 / ❓ 待动态验证。

## 1. 地址空间总览

```
$0000–$07FF  内部 RAM（2KB，$0800–$1FFF 为镜像）
$2000–$2007  PPU 寄存器（8 个，$2008–$3FFF 镜像）
$4000–$4013  APU 脉冲/三角/噪声
$4014        OAM DMA（写 $XX00 页）
$4015        APU 状态
$4016        手柄 1（读）/ APU 帧计数器（写）
$4017        手柄 2（读）/ APU 帧计数器（写）
$8000–$BFFF  PRG 可切换银行（16KB，MMC1 PRG 寄存器）
$C000–$FFFF  PRG 固定银行（16KB，银行 7）
PPU $0000–$1FFF  图案表（CHR ROM，MMC1 CHR0/CHR1）
PPU $2000–$2FFF  Nametable（垂直镜像：$2000/$2400/$2800/$2C00）
PPU $3F00–$3F1F  调色板（32 色）
```

## 4. PPU / APU 寄存器速查

PPU：`$2000` PPUCTRL、`$2001` PPUMASK、`$2002` PPUSTATUS（读清 w 切换）、`$2003` OAMADDR、`$2004` OAMDATA、`$2005` PPUSCROLL、`$2006` PPUADDR、`$2007` PPUDATA。
APU：`$4000–$4003` 脉冲 1、`$4004–$4007` 脉冲 2、`$4008–$400B` 三角、`$400C–$400F` 噪声、`$4015` 状态、`$4017` 帧计数器（`$C0`=禁 IRQ + 4 步进）。

## 5. GMS 映射提示

- 零页变量 → GMS `global` 变量或 `obj_game` 的成员变量（`$29/$2A` 影子、`$38/$3C` 手柄等）
- `$0600` OAM → GMS 实例列表（每精灵一实例，`depth` 按 OAM 优先级）
- `$0700` 实体数组 → GMS 实体对象池（`obj_entity` + `ds_list`）
- `$053A` 队列 → GMS 绘制队列（每帧限量上传，避免卡顿——原版在 NMI 里处理）
- 详见 `docs/07-gms-mapping.md`
