Banks 26-27: mech graphics, "THE END", character portraits
Bank  28   : large round boss
Banks 29-30: title screen ("CHIP 'N DALE", "RESCUE RANGERS 2", Disney logo)
Bank  31   : font (0-9, A-Z, a-z, punctuation, heart)

NOTE ON SPRITES
---------------
The small in-game character frames (Chip, Dale, enemies, items) are defined
by OAM (sprite) data stored in PRG, which specifies how the 8x8 CHR tiles
combine into each frame. They are not directly readable from the CHR tile
order alone. To obtain pixel-perfect in-game sprite frames, use Mesen's
PPU Viewer (see GUIDE_STEP_BY_STEP.md, Appendix B). The GML code is
structured so sprites can be swapped in without changing any logic.
